# 🏦 Рекомендательный сервис банка «Стар»

Сервис для формирования персональных финансовых рекомендаций для клиентов банка.

**Статус:** MVP в активной разработке (с 26.01.2026 по 15.02.2026)

## 🚀 Быстрый старт (за 5 минут)

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/Vasechko-M/-Bank-Star.git bank-star
    cd bank-star
    ```
2.  **Запустите в Docker (требуется Docker Desktop):**
    ```bash
    docker-compose up -d
    ```
3.  **Приложение будет доступно по адресу:** [http://localhost:8080](http://localhost:8080)
4.  **Документация API (Swagger UI):** [http://localhost:8080/swagger-ui.html](http://localhost:8080/swagger-ui.html)
